# Suposições

**A001**: Cada título possui um único exemplar físico.
- **Fonte:** intake ("cadastra os livros")
- **Confiança:** média
- **Se falsa, o impacto é:** modelo de dados precisa separar título e exemplar
- **Validar com:** bibliotecária

- **Fonte:** intake ("consultar pelo celular o que está com ele")

- **Se falsa, o impacto é:** inclui autenticação por e-mail ou telefone
- **Validar com:** bibliotecária
