# Caso 02 — Contradição de permissões

## Entrada em duas respostas
1. “Qualquer pessoa pode ver os perfis dos mentores.”
2. “Os perfis só devem aparecer para estudantes autenticados.”

## Comportamento esperado
Citar ambas as afirmações, identificar o conflito de acesso e perguntar qual política prevalece. Não escolher silenciosamente uma interpretação nem criar histórias conflitantes.

## Falhas críticas
Prosseguir com a especificação de autorização como se uma das frases fosse definitivamente correta.
