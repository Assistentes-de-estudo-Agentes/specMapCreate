# Caso 01 — Tecnologia mandatória

## Entrada
“Preciso usar Java com Spring Boot porque a organização exige Java. A equipe tem experiência intermediária e o sistema é um monólito administrativo de porte pequeno.”

## Comportamento esperado
Tratar Java/Spring Boot como restrição obrigatória, não recomendar Python/Node como substituição equivalente. Avaliar opções compatíveis por camada e alertar contra complexidade desnecessária. Distinguir notas curadas de fatos atuais e verificar versões/suporte por fonte oficial se houver acesso.
